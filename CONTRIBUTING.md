# Contributing Policy / コントリビューション方針

本リポジトリ（`antigravity-multiagent-setup-ja`）に興味を持っていただきありがとうございます。

## 📌 Pull Request・Issue の受付について（No PRs / Fork-Friendly）

本リポジトリは、**Haratakeshi 個人の Antigravity 運用理念・ルール・マルチエージェント構成をオープンに共有するためのリファレンス公開リポジトリ**です。

個人の日常開発フローと密結合して継続的に調整・運用しているため、**原則として外部からの Pull Request（PR）および Issue は受け付けておりません**（PR が作成された場合は GitHub Actions により自動でクローズされます）。

## 🍴 推奨される活用方法（Fork & Customize）

MIT ライセンスのもとで公開していますので、以下の用途で自由にご活用ください：

1. **そのまま導入する**: お手元の Antigravity に「このリポジトリを見てセットアップして」と指示するか、`python3 scripts/install.py` を実行して導入できます。
2. **Fork して自分専用に育てる**: ご自身の開発スタイル・使用言語・チーム規約に合わせて **Fork** し、`gemini/GEMINI.md` や各プラグイン・スキルを自由に改変・再配布していただけます。
